# Codex Project Instructions

Before modifying authentication or authorization:

1. Read `docs/AUTH_SECURITY_PROGRESS.md`.
2. Run `git status`.
3. Run `git log --oneline -10`.
4. Inspect current source code.
5. Current source code overrides documentation if they conflict.
6. Do not modify unrelated modules.
7. Do not invent backend APIs that do not exist.
8. Do not commit unless explicitly requested.
9. After each auth/security phase, update `docs/AUTH_SECURITY_PROGRESS.md`.
